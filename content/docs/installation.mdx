# Installation

NextDeploy is a single self-contained CLI binary (written in Go) plus a daemon
(`nextdeployd`) that runs on your servers. The CLI is **not** an npm package —
you install it with a one-line script or by downloading a release binary.

## Requirements

- **Operating system** — Linux, macOS, or Windows.
- **`curl`** and **`jq`** — used by the install scripts to fetch the latest release.
- **Node.js** — only for *your* Next.js project (so `nextdeploy ship` can run `next build`). The CLI itself has no Node dependency.

<Info>
For VPS deployments you'll also need a server with SSH access and `ansible-playbook`
on your machine. See the [VPS Deployment guide](/docs/targets/vps) for the full setup.
</Info>

    <h3 className="text-xl font-semibold">Install script (Linux & macOS)</h3>
    <p>The recommended way to install NextDeploy:</p>

    <CodeBlock title="Install NextDeploy CLI" language="bash">
{`curl -fsSL https://nextdeploy.org/install.sh | bash`}
    </CodeBlock>

    <p>
      This downloads the latest release binary for your OS and architecture into
      <code>~/.local/bin/nextdeploy</code> and adds it to your <code>PATH</code>.
      Prefer to do it by hand? Pull the binary straight from GitHub releases:
    </p>

    <CodeBlock title="Manual binary download" language="bash">
{`# Pick the latest tag and your arch (amd64 / arm64)
TAG=$(curl -s https://api.github.com/repos/aynaash/NextDeploy/releases/latest | jq -r .tag_name)
VERSION=\${TAG#v}                            # strip the leading "v" for the filename
ARCH=$(uname -m); [ "$ARCH" = "x86_64" ] && ARCH=amd64; [ "$ARCH" = "aarch64" ] && ARCH=arm64
OS=$(uname | tr '[:upper:]' '[:lower:]')   # linux or darwin

# Release assets are GoReleaser tarballs: nextdeploy_<version>_<os>_<arch>.tar.gz
mkdir -p ~/.local/bin
curl -L "https://github.com/aynaash/NextDeploy/releases/download/\${TAG}/nextdeploy_\${VERSION}_\${OS}_\${ARCH}.tar.gz" \\
  | tar -xz -C ~/.local/bin nextdeploy
chmod +x ~/.local/bin/nextdeploy

# Make sure ~/.local/bin is on your PATH
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc && source ~/.bashrc`}
    </CodeBlock>

    <Success>
      Once it's on your <code>PATH</code>, the <code>nextdeploy</code> command works from any directory.
    </Success>
  </TabsContent>

## Verify

After installing, confirm the CLI is on your `PATH`:

<CodeBlock title="Verify installation" language="bash">
{`nextdeploy --version    # print the installed version
nextdeploy --help       # list available commands`}
</CodeBlock>

<Info>
If you see <code>command not found</code>, restart your shell or run
<code>export PATH="$HOME/.local/bin:$PATH"</code> (the install location used by the script).
</Info>

## What you get

The `nextdeploy` CLI drives every deployment target from one config file
(`nextdeploy.yml`). The commands you'll use most:

<CodeBlock title="Core commands" language="bash">
{`nextdeploy init      # scaffold nextdeploy.yml in your Next.js repo
nextdeploy prepare   # provision a fresh VPS (VPS target only)
nextdeploy plan      # show what will happen, change nothing
nextdeploy ship      # build + push + deploy to your target
nextdeploy logs -f   # tail production logs
nextdeploy rollback  # revert to a previous release
nextdeploy status    # show the active release`}
</CodeBlock>
