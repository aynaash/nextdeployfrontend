# NextDeploy Frontend

Marketing site and documentation for **[NextDeploy](https://github.com/aynaash/NextDeploy)** — self-hosted deployment for Next.js. Built with Next.js 16, React 19, Tailwind CSS v4, and shadcn/ui.

Live: **[nextdeploy.org](https://nextdeploy.org)**

## Develop

```bash
bun install
bun dev
```

Docs live in `content/docs/` as Markdown.
